# Spells.eff File Reference

## Overview

Spells.eff is a binary file that contains the "classic" spell effects data for EverQuest. These effects can be enabled at least up to the TAKP/EQMac client, but having spell effects on, and removing the spellsnew.eff and spellsnew.edd files from your EverQuest client files folder. The files is always 714,752 bytes, and contains 256 spell effects records that are 0xAE8 bytes in size
